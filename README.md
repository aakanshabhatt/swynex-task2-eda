# Swynex Task 2 — Exploratory Data Analysis (EDA)

## Project Overview
Performed Exploratory Data Analysis on an employee dataset using PostgreSQL and Microsoft Excel to identify patterns, trends, and data-quality issues.

## Tools Used
- PostgreSQL (SQL queries and analysis)
- Microsoft Excel (PivotTables, charts, and dashboard)

## Analysis Performed
- Employee distribution by department and status
- Performance score distribution
- Average salary by department
- Hiring trends from 2020 to 2024
- Remote vs non-remote work distribution
- Missing-value and duplicate ID checks

## Key Findings
- Total records analysed: 1,020 employees
- DevOps had the highest employee count.
- Sales had the highest average departmental salary.
- Hiring peaked in 2023.
- Remote and non-remote employees were nearly evenly distributed.
- Missing values were identified in Age, Salary, and Phone.

## Project Files
- `Swynex_Task2_EDA.xlsx` — Excel workbook with PivotTables, charts, and insights
- `Swynex_Task2_EDA.sql` — SQL queries used for analysis
- `Swynex_Task2_EDA_Dashboard.png` — Dashboard preview
